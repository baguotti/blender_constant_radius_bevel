**CR Bevel 1.0.6: faster**

Same results, less waiting.

### Faster
- **Clamp Per Edge: 3–23× faster.** 26 s → 7.7 s on an 81,000-face test mesh, 8.1 s → 0.35 s on a subdivided Suzanne.
- **Default settings: up to 3× faster** on typical models where only the sharp edges are rounded (0.30 s → 0.10 s on the Suzanne test). With every edge rounded, the time is now mostly Blender's own bevel and its custom-normal encoding.
- **Analytic Normals off:** about 1.2× the native bevel.

Details and measurements: [docs/PERFORMANCE.md](https://github.com/baguotti/blender_constant_radius_bevel/blob/main/docs/PERFORMANCE.md).

### Install
Download **`cr_bevel-1.0.6.zip`** below, then in Blender: **Edit > Preferences > Get Extensions**, open the drop-down at the top right, choose **Install from Disk…** and pick the zip. Requires Blender 5.2 LTS or newer.

**Updating:** files made with an older version keep their own copy of the node group. To use the new one in an existing file, delete the old "CR Bevel" node group, then add the modifier again.
