**CR Bevel 1.0.3: constant-radius (rolling-ball) bevel for Blender 5.2+**

Rounds edges with a true constant radius: exact circular arcs, exact spherical corners, and shading that follows the true surface. It's a Geometry Nodes modifier built on Blender's Mesh Bevel node.

### Install
1. Download **`cr_bevel-1.0.3.zip`** below. Don't unzip it.
2. In Blender: **Edit > Preferences > Get Extensions**, open the drop-down at the top right, choose **Install from Disk…**, and pick the zip.
3. Select a mesh, then **Add Modifier > Generate > CR Bevel**.

Requires **Blender 5.2 LTS or newer**.

### Highlights
- Exact constant radius on every edge, convex and concave.
- Exact corners: a sphere where 3 edges meet, the exact intersection where 2 meet, clean ends on slanted faces.
- Exact shading via custom normals; your own smooth/flat shading is kept on original faces; works with deform modifiers placed after it.
- Overlap clamp (Uniform, Per Edge or None), with a warning when the radius is lowered.
- Safe on messy meshes. Where no exact answer exists, Blender's native bevel is kept.

See the [README](https://github.com/baguotti/blender_constant_radius_bevel#readme) for every setting, workflows, what is exact, and known limitations.
