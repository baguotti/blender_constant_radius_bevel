**CR Bevel 1.1.0: choose edges like Blender's Bevel, scaled objects just work**

### New
- **Edges menu:** round edges by **Angle** (as before), **Bevel Weight**, **Sharp Edges** (Mark Sharp) or **Seams** (Mark Seam). Angle Limit applies to Angle only. If nothing is marked, the modifier says so.
- **Radius × bevel weight:** in Bevel Weight mode each edge is rounded at Radius × its weight, like Blender's Bevel modifier. Clamp Uniform keeps the ratios between edges. Polylines follow the weights too.
- **CR Bevel (Scene Units):** a second entry in Add Modifier > Generate. The radius is in scene units, and rounds stay truly circular on scaled objects, also with non-uniform scale or a scaled parent; shading normals are exact too. Because it follows the object's scale, it re-evaluates whenever the object moves, so it's a separate choice: plain **CR Bevel** is unchanged (object units, like Blender's Bevel) and costs nothing when objects move.

### Fixed
- Rounds made from sharp-marked edges no longer come out marked sharp inside (faceted shading with Analytic Normals off, splits on export).
- A round that stops against a face almost parallel to it (e.g. one weighted edge on a curved rim) no longer throws vertices far away; that end keeps the native shape.

### Also
- Version 1.0.6 made Clamp Per Edge 3–23× faster and typical models up to 3× faster ([details](https://github.com/baguotti/blender_constant_radius_bevel/blob/main/docs/PERFORMANCE.md)).

### Note for existing files
Files that already use CR Bevel keep their old node group until you add CR Bevel again (delete the old "CR Bevel" node group first). The Edges menu then appears; results with the default settings are unchanged.

### Install
Download **`cr_bevel-1.1.0.zip`** below, then in Blender: **Edit > Preferences > Get Extensions**, open the drop-down at the top right, choose **Install from Disk…** and pick the zip. Requires Blender 5.2 LTS or newer.
