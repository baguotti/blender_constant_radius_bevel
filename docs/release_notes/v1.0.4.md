**CR Bevel 1.0.4: open meshes and polylines**

### New
- **Open meshes are exact.** A rounded edge that runs out at an open border (a mesh with missing faces) used to fall back to Blender's native, non-circular profile at that end. It's now exact, ending in the plane of the missing face, which is defined by the two border edges.
- **Polylines (Wire Corners).** Corners of loose edges (wires without faces) are rounded with true circular arcs of the same radius, like the Bevel modifier's *Vertices* mode. On by default; open ends stay where they are.

### Install
Download **`cr_bevel-1.0.4.zip`** below, then in Blender: **Edit > Preferences > Get Extensions**, open the drop-down at the top right, choose **Install from Disk…** and pick the zip. Requires Blender 5.2 LTS or newer.

**Updating:** files made with an older version keep their own copy of the node group. To use the new one in an existing file, delete the old "CR Bevel" node group, then add the modifier again.
